# AI Bug Tracker - Role-Based Dashboards

## Live Demo
https://ai-bug-tracker-website-krmb.vercel.app

## Features
- **Admin**: Full dashboard + employee management
- **Employees**: Personal/company bugs (dev/tester roles)
- **External Users**: Register → report bugs with images
- AI severity prediction, image upload, Supabase backend
